A small TypeScript program that writes one short text to /output/entry.txt — a library book returned forty years late, a margin note in the librarian's own handwriting, and one new line in pencil, in her hand, that she never wrote — written to make the AI judge reading it feel curious.

## Run it

```sh
node main.ts
```
